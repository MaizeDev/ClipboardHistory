# ClipboardHistory 1.0 人工验收清单

这份清单供项目完成后逐项手动验证。编译成功不代表这些操作已经人工测试。

## 安装与启动

- [ ] 从 DMG 把应用拖到“应用程序”后可以启动。
- [ ] 启动后不出现普通主窗口，只在菜单栏显示图标。
- [ ] 退出并重新打开后，历史数据仍然存在。

## 剪贴板记录

- [ ] 复制纯文字后出现一条文字卡片。
- [ ] 复制带格式文字后可显示内容，并能再次复制。
- [ ] 复制图片后出现缩略图，并能再次复制。
- [ ] 在 Finder 复制图片文件后显示内容缩略图，并能再次复制。
- [ ] 在 Finder 复制视频文件后显示预览帧，并能再次复制。
- [ ] 不支持预览或原文件失效时回退到文件图标，不闪退。
- [ ] 重复复制相同内容不会生成多条重复记录，而是移动到顶部。
- [ ] 应用自己写回剪贴板的内容不会再次记录。

## 浮窗与搜索

- [ ] `⇧⌘C` 可以显示和关闭浮窗。
- [ ] 浮窗显示在鼠标所在显示器中央，不被菜单栏或 Dock 遮挡。
- [ ] 搜索可以匹配文字、文件名和来源应用。
- [ ] 没有记录和没有搜索结果时，提示内容正确。

## 鼠标与键盘

- [ ] 单击卡片只改变选中状态。
- [ ] 双击卡片会复制内容并关闭浮窗。
- [ ] `↑` / `↓` 移动选中项并自动滚动到可见位置。
- [ ] `Enter` 复制选中内容并关闭浮窗。
- [ ] `Option + Enter` 对文字记录使用与默认设置相反的复制方式。
- [ ] `⌘1`～`⌘9` 选择对应位置的记录。
- [ ] `Delete` 和 `Backspace` 删除选中记录。
- [ ] `⌘P` 固定和取消固定，固定记录排列在顶部。
- [ ] 点击卡片图钉可以固定和取消固定；固定第 4 条时，最早固定的一条自动取消。
- [ ] 点击卡片星标可以收藏和取消收藏。
- [ ] “收藏”选项卡只显示收藏内容，切回“历史”仍能看到最近记录。
- [ ] `⇧⌘F` 收藏和取消收藏当前选中记录。
- [ ] `Esc` 关闭浮窗。
- [ ] 中文输入法选词时，回车不会误触发复制。
- [ ] 文字卡片始终显示“保留格式”和“纯文本”，鼠标移入时卡片高度不变化。
- [ ] 搜索框有文字时，Backspace 删除搜索文字而不是删除历史记录。

## 偏好设置

- [ ] 菜单栏右键选择“偏好设置”可以打开设置窗口。
- [ ] 修改呼出浮窗、固定、收藏或另一种复制方式的快捷键后，新快捷键立即生效。
- [ ] 设置重复快捷键时会提示冲突，不会覆盖已有操作。
- [ ] 系统主要语言为简体中文时，系统快捷键冲突弹窗显示中文。
- [ ] “通用”“快捷键”和“隐私”在默认窗口中无需页面整体滚动即可查看。
- [ ] 修改默认复制方式后，`Enter` 会按新方式复制。
- [ ] 文字和富文本卡片始终显示“保留格式”和“纯文本”，两个按钮都可用。
- [ ] 修改历史数量后，只自动清理超出的普通记录，固定和收藏记录继续保留。
- [ ] 清空全部历史前会要求确认，确认后固定和收藏记录也被删除。
- [ ] 添加忽略应用后，从该应用复制的新内容不再记录。
- [ ] 密码管理器标记为机密或临时的内容不会进入历史记录。
- [ ] 开启“登录 Mac 时自动启动”后，系统设置中状态一致。

## 发布包

- [ ] DMG 中包含应用和“应用程序”快捷方式。
- [ ] DMG 文件名、应用版本和 Git tag 使用同一个版本号。
- [ ] 打开 DMG 后只显示应用和“应用程序”文件夹，背景、箭头及图标位置正确。
- [ ] DMG 中没有安装说明文件。
- [ ] 正式 DMG 的签名检查通过。
- [ ] 正式 DMG 的 Apple 公证和 stapler 检查通过。
- [ ] 从 GitHub Release 重新下载后仍能完成安装与启动。
