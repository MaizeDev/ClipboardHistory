# ClipboardHistory 1.2 人工验收清单

这份清单供项目完成后逐项手动验证。编译成功不代表这些操作已经人工测试。

自动化逻辑测试：

```bash
./scripts/run_logic_tests.sh
```

该脚本应输出“全部通过”。它覆盖文件路径存储、附加格式、搜索、历史增删/固定/清理和撤销恢复，但仍不能替代下面的界面与系统集成验收。

## 安装与启动

- [ ] 从 DMG 把应用拖到“应用程序”后可以启动。
- [x] 启动后不出现普通主窗口，只在菜单栏显示图标。
- [ ] 退出并重新打开后，历史数据仍然存在。
- [ ] 从旧版本升级后，原有历史仍然存在；如数据库被重建，能看到备份提示。

## 剪贴板记录

- [x] 复制纯文字后出现一条文字卡片。
- [x] 复制带格式文字后可显示内容，并能再次复制格式。
- [x] 从浏览器复制 HTML 内容后，“保留格式”粘贴能还原链接/样式。
- [x] 复制图片后出现缩略图，并能再次复制。
- [x] 在 Finder 复制图片文件后显示内容缩略图，并能再次复制。
- [x] 在 Finder 复制视频文件后显示预览帧，并能再次复制。
- [x] 在 Finder 一次复制多个文件，历史里保留全部文件，粘贴也是全部文件。
- [ ] 一次复制多个文件时，卡片用一排缩略图展示所有文件；超过 5 个时最后一块显示“+N 个文件”。
- [ ] 复制超过 20 MB 的大截图：应自动压缩后记录，不静默丢失。
- [x] 不支持预览或原文件失效时回退到文件图标，不闪退；复制该条会提示失败原因。
- [x] 重复复制相同内容不会生成多条重复记录，而是移动到顶部。
- [x] 同一段文字从不同应用再次复制时，格式快照会更新为最近一次。
- [ ] 应用自己写回剪贴板的内容不会再次记录。
- [x] 菜单栏选择“暂停记录”后复制内容不进入历史；恢复后新内容正常记录。

## 浮窗与搜索

- [x] `⇧⌘C` 可以显示和关闭浮窗。
- [x] 浮窗显示在鼠标所在显示器中央，不被菜单栏或 Dock 遮挡。
- [x] 搜索可以匹配文字、文件名和来源应用。
- [ ] 在 1,000 条以上记录时输入搜索词，浮窗仍可操作，不出现明显卡死。
- [x] 没有记录和没有搜索结果时，提示内容正确。
- [x] 关闭再打开浮窗后，搜索词为空、回到“历史”分区、选中第一条。

## 鼠标与键盘

- [x] 单击卡片只改变选中状态。
- [x] 双击卡片会复制内容并关闭浮窗。
- [x] `↑` / `↓` 移动选中项并自动滚动到可见位置，列表不会来回跳到中央。
- [x] `Enter` 复制选中内容并关闭浮窗。
- [x] `Option + Enter` 对文字记录使用与默认设置相反的复制方式。
- [x] `⌘1`～`⌘9` 选择对应位置的记录。
- [x] `Delete` 和 `Backspace` 删除选中记录。
- [x] 删除后 5 秒内浮窗底部出现“撤销”，点击或按 `⌘Z` 恢复记录。
- [ ] 删除后立即清空全部历史，再按 `⌘Z` 不应恢复任何记录。
- [x] `⌘P` 固定和取消固定，固定记录排列在顶部。
- [x] 点击卡片图钉可以固定和取消固定；固定第 4 条时，最早固定的一条自动取消。
- [x] 点击卡片星标可以收藏和取消收藏。
- [x] “收藏”选项卡只显示收藏内容，切回“历史”仍能看到最近记录。
- [x] `⇧⌘F` 收藏和取消收藏当前选中记录。
- [x] `Esc` 在搜索框有内容时清空搜索；搜索为空时关闭浮窗。
- [x] 中文输入法选词时，回车不会误触发复制。
- [x] 文字卡片始终显示“保留格式”和“纯文本”，鼠标移入时卡片高度不变化。
- [x] 搜索框有文字时，Backspace 删除搜索文字而不是删除历史记录。

## 偏好设置

- [x] 菜单栏右键选择“偏好设置…”，只打开一个设置窗口。
- [x] 重复点击“偏好设置…”不会叠加出多个窗口，已打开时窗口回到前台。
- [ ] 左侧“通用 / 快捷键 / 隐私”可以正常切换，选中状态清晰。
- [x] 修改呼出浮窗、固定、收藏或另一种复制方式的快捷键后，新快捷键立即生效。
- [ ] 设置重复快捷键时会在窗口内提示冲突，不会覆盖已有操作，录制状态不中断。
- [ ] 冲突提示出现和消失时，录制按钮、行内文字及页面其他内容不会上移或跳动。
- [ ] 清空某个快捷键后关闭窗口再打开，仍然可以录制新的组合键。
- [x] 尝试把快捷键设为 `⌘C` / `⌘V` / `⌘Z` / 方向键时会被拒绝。
- [x] “通用”“快捷键”和“隐私”在默认窗口中无需页面整体滚动即可查看。
- [x] 修改默认复制方式后，`Enter` 会按新方式复制。
- [x] 修改历史数量后，只自动清理超出的普通记录，固定和收藏记录继续保留。
- [ ] 设置“自动删除旧记录”天数后，超期普通记录被删除，固定和收藏保留。
- [x] 清空全部历史前会要求确认，确认后固定和收藏记录也被删除。
- [x] 存在数据库备份时，清空确认框提供“清空并删除备份”，选择后备份目录被清空。
- [x] 添加忽略应用后，从该应用复制的新内容不再记录。
- [x] 从被忽略应用复制后立刻切到别的应用，内容仍不应被记录。
- [ ] 没有把“密码”加入忽略应用时，从 Apple“密码”App 复制密码也不会进入历史记录。
- [x] 开启“登录 Mac 时自动启动”后，系统设置中状态一致。
