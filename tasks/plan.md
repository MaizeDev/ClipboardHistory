# ClipboardHistory M5 体验与隐私重设计方案

## 目标

在不扩张产品范围的前提下，解决当前菜单栏图标、文件预览、时间显示、偏好设置布局和隐私规则的问题，并补齐“保留格式复制 / 纯文本复制”的明确操作入口。

本方案已于 2026-08-09 完成实现，通过 Debug 与 Release 编译，并由用户完成人工验收。v1.0.0 DMG 已生成并通过完整性、架构和临时签名检查，进入 GitHub 发布阶段。

## 实施状态

- M5-1：已完成。菜单栏改为单色系统图标，移除普通流程控制台输出。
- M5-2：已完成。Finder 图片、视频和常见文件使用 Quick Look 异步缩略图并缓存。
- M5-3：已完成。时间改为中文分钟级相对时间，列表每分钟统一刷新。
- M5-4：已完成。设置窗口重排为 680 × 520 pt，并自动过滤机密/临时剪贴板类型。
- M5-5：已完成。支持保留格式和纯文本两种复制方式。
- 当前阶段：人工验收通过；v1.0.0 已发布，随后以 v1.0.1 改进 DMG 安装窗口，不覆盖旧版本附件。

## 当前结论

### 控制台信息

- `linkd.autoShortcut` 和 `AFIsDeviceGreymatterEligible` 出现在 App 自己的启动日志之前，属于 macOS/Xcode 系统服务输出，不是剪贴板保存失败。
- 不添加来历不明的 entitlement，也不使用私有接口压制系统日志。
- 移除普通流程中的 `print`，仅保留真正失败时的统一日志。
- Debug 环境仍可能出现系统日志；正式 Release 版本以功能是否正常和 App 自己是否报告错误为判断标准。

### 文件预览

- 截图工具复制的是 PNG/TIFF 图片数据，现有代码可以直接显示。
- Finder 复制图片或视频文件时，剪贴板提供的是文件 URL；现有卡片只读取文件图标，所以没有内容缩略图。
- 使用 Apple 的 Quick Look Thumbnailing 为图片、视频、PDF 等文件异步生成缩略图，失败时回退到文件图标。

### 复制与粘贴

- 当前选择历史记录只会把内容写回系统剪贴板并关闭窗口，不会自动向原应用发送粘贴按键。
- 纯文本记录本身已经是纯文本。
- 富文本记录目前同时写入 RTF 和普通文字，目标应用通常会优先使用带格式版本，因此还不等于“强制纯文本”。
- M5 增加“保留格式复制”和“纯文本复制”；自动粘贴需要辅助功能权限，暂列为后续可选功能。

## 设计决策

### 1. 菜单栏图标

- Finder 中的 App 图标继续使用彩色图标。
- 菜单栏改用单色 SF Symbol `doc.on.clipboard`，设置为 template image，自动适应浅色、深色和不同菜单栏背景。
- 不在菜单栏缩小彩色 App 图标，避免与系统状态图标风格冲突。

### 2. 历史卡片

- 图片数据继续显示现有图片预览。
- 文件 URL 使用 `QLThumbnailGenerator` 请求最大约 160 × 110 pt 的预览。
- 图片文件和视频文件显示内容缩略图；其他文件优先显示 Quick Look 预览，无法生成时显示系统文件图标。
- 缩略图异步加载并缓存；快速滚动时不阻塞主界面。
- 文件已经移动、删除或无权访问时显示清楚的回退状态。

### 3. 时间显示

- 小于 1 分钟：`刚刚`。
- 1–59 分钟：`N 分钟前`。
- 1–23 小时：`N 小时前`。
- 1–6 天：`N 天前`。
- 更早：显示简短日期。
- 整个列表每分钟统一刷新一次，不让每张卡片持续读秒。

### 4. 偏好设置

- 保留“通用”和“隐私”两个标签页。
- 固定内容尺寸建议为 680 × 520 pt；首次打开即完整展示当前标签页的主要内容。
- 不使用包住整个页面的滚动视图。
- “忽略的应用”超过可见数量时，仅应用列表内部滚动；无限数量的应用无法在固定窗口中全部同时显示。
- “忽略规则”改名为“隐私”。
- 删除面向用户的“忽略的内容类型”。用户通常不会希望完全停止记录文字、图片或文件。

### 5. 隐私保护

- 自动忽略剪贴板声明为临时、机密或自动生成的内容。
- 内置兼容常见密码管理器使用的机密 pasteboard 类型。
- 保留“忽略的应用”，让用户添加 macOS 密码、钥匙串访问、1Password、Bitwarden、KeePassXC、验证码工具或其他个人认为敏感的应用。
- 不通过文字内容猜测密码。普通字符串无法可靠判断是密码、验证码还是正常文字，误判风险太高。
- 可以在菜单栏后续增加“一次性暂停记录”，用于临时复制敏感内容；不放进本轮必做范围。

### 6. 保留格式与纯文本

- 在通用设置增加“默认复制方式”：`保留格式` / `纯文本`。
- `Enter` 执行默认复制方式并关闭浮窗。
- `Option + Enter` 执行另一种复制方式并关闭浮窗。
- 文字和富文本卡片在鼠标悬停或选中时显示两个紧凑操作：`保留格式`、`纯文本`。
- 图片和文件不显示纯文本操作。
- 卡片按钮实际含义是“写入系统剪贴板”，界面文案使用“复制”而不是“粘贴”，避免承诺尚未实现的自动粘贴。

### 7. 自动粘贴（后续可选）

- 若启用，选择记录后需要向原应用发送 `Command + V`。
- 这需要用户在“系统设置 → 隐私与安全性 → 辅助功能”授权。
- 默认关闭，并保留无需权限的手动粘贴方式。
- 只有用户确认确实需要后，再作为 M6 单独实现。

## 实施顺序

### M5-1：控制台与菜单栏图标

范围：小。

- 将菜单栏图标恢复为单色 template SF Symbol。
- 将普通启动、保存成功等 `print` 移除或降为仅开发时可选日志。
- 保留真正失败时的错误日志。
- 分别编译 Debug 和 Release。

验收：菜单栏图标能随背景自动变色；App 自己不再输出大量普通流程信息；系统日志不会被误判为功能故障。

### M5-2：Finder 文件缩略图

范围：中。

- 新增独立的 Quick Look 缩略图服务和内存缓存。
- 文件卡片异步显示图片、视频和常见文档缩略图。
- 文件不存在或缩略图失败时回退到系统文件图标。

验收：Finder 复制图片和视频后，卡片能显示预览；滚动不卡顿；删除原文件后卡片不崩溃。

### M5-3：分钟级相对时间

范围：小。

- 新增统一相对时间格式化器。
- 列表每分钟刷新，不再显示秒数。

验收：新记录显示“刚刚”，随后显示“1 分钟前”“1 小时前”等自然语言。

### 检查点 A

- Debug 与 Release 均编译成功。
- 用户验证菜单栏图标、文件预览和时间显示。

### M5-4：偏好设置与隐私规则

范围：中。

- 将偏好设置重排为固定尺寸的“通用 / 隐私”。
- 删除“忽略的内容类型”界面和对应逻辑。
- 增加内部机密/临时 pasteboard 类型过滤。
- 保留并优化“忽略的应用”。
- 旧版 `ignoredContentTypes` 设置不再生效，避免升级后仍意外漏记内容。

验收：两个标签页在默认窗口中完整显示；没有页面级滚动；机密标记内容不会进入历史；被忽略应用仍正常工作。

### M5-5：保留格式与纯文本复制

范围：中。

- 新增复制模式和默认复制方式设置。
- 接入 Enter、Option + Enter 和文字卡片操作按钮。
- 非文字内容保持现有复制逻辑。

验收：富文本可分别复制为带格式和纯文本；文字卡片操作清楚；图片与文件不会出现无意义的纯文本按钮。

### 检查点 B

- 完整编译成功。
- 用户按手动清单逐项验证。
- 通过后再决定是否提交、推送和制作 DMG。

## 暂不纳入 M5

- 自动向原应用粘贴（需要辅助功能权限）。
- 多文件同时复制的完整支持。
- OCR 图片文字识别。
- 云同步、App Store 上架和统计服务。

## 主要风险与处理

| 风险 | 影响 | 处理 |
| --- | --- | --- |
| Quick Look 生成缩略图需要时间 | 快速滚动时卡顿 | 异步生成、缓存、取消离屏请求 |
| 原文件被移动或删除 | 缩略图失败 | 回退到文件图标和明确提示 |
| 密码以普通文字复制 | 无法可靠自动识别 | 尊重机密类型标记并允许忽略来源应用 |
| 固定设置窗口中忽略应用过多 | 无法同时展示全部行 | 只让应用列表区域在必要时滚动 |
| 自动粘贴需要高权限 | 增加信任和支持成本 | 延后到 M6，默认关闭 |

## 参考依据

- Apple Quick Look Thumbnailing：为图片、视频、PDF、文字等文件生成缩略图。
- Apple RelativeDateTimeFormatter 与 TimelineView：本地化相对时间并按分钟刷新。
- Maccy：区分选择、自动粘贴、纯文本粘贴，并默认忽略临时/机密 pasteboard 类型。
